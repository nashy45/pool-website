🚀 DEPLOYMENT TO PRODUCTION:

When ready to deploy to a real server:

1. Choose hosting (DigitalOcean, Render, Railway, etc.)
2. Get a domain name
3. Set up HTTPS/SSL
4. Update .env file:
   - Change JWT_SECRET to a secure random string
   - Set PUBLIC_URL to your actual domain
   - Set NODE_ENV=production
5. Upload code to server
6. Run: npm install
7. Run: npm run init-db
8. Run: npm run create-admin
9. Start server with PM2 or similar
10. Set up Nginx reverse proxy (recommended)
